# fashion attribute v25-10


#### extract data

firstly let's get all the data from elasticsearch:
`extract/product-attributes-extractor.http` - helps to run elasticsearch query to get the product attributes
`extract/product-images-extractor.py` - downloads all the images for the extracted products

`image-descriptions-export.py` - generates the descriptions for the extracted images using BLIP model


now we have
- image embeddings generated by Vit
- image text descriptions generated by BLIP
- product catalog descriptions fetched from elasticsearch

Then we need to populate the vectors at FAISS index to perform the search.
To do so we'd need to generate the vectors based on the text descriptions and image  embeddings

- we need to combine text descriptions generated by Blip with product catalog descriptions
- generate the embeddings out of descriptions
- normalize descriptions embeddings and images embeddings
- concatente the normalized embeddings and put them into FAISS index

Those operations are performed within running `populate_faiss_index.py`

Test the search on running `search_product.py`
